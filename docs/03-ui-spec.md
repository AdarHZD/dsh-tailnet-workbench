# UI 规范

目标：换一台机器部署后，工作台看起来和 README 截图一致。所有尺寸、颜色、阈值都从这里取，不靠记忆。

## 页面结构

```
┌ 顶部标签栏（sticky） ─────────────────────────────┐
│ [工作台] [DSH]                    ● 全部正常  ↻   │
└──────────────────────────────────────────────────┘
┌ 设备 · N ────────────┐ ┌ DSH 主机 ──────────────┐
│ 图标 名称             │ │ DSH 界面    ● 运行中    │
│      系统 · tailnet IP│ │ 常驻托管  ● launchd/任务│
│            时延 直连 ● │ │ 工作区      14          │
│ ...                   │ │ 会话        613 · 最近… │
└───────────────────────┘ │ Tailscale  ● 100.x.y.z  │
                          └─────────────────────────┘
更新于 21:02:30
```

- 只有两个内容卡：**设备**、**DSH 主机**。诊断卡仅在有问题时出现，横跨两列。
- 不出现：存储、入口链接、文件面板、流量统计、主题切换、设置、登录框。
- 顶部标签栏在滚动时固定在顶部；DSH 视图下标签栏保持可见。

## 设计令牌

| 令牌 | 浅色 | 深色 |
|---|---|---|
| `--bg` | `#f5f5f7` | `#000` |
| `--card` | `#fff` | `#1c1c1e` |
| `--line` | `rgba(0,0,0,.08)` | `rgba(255,255,255,.1)` |
| `--text` | `#1d1d1f` | `#f5f5f7` |
| `--dim` | `#86868b` | `#98989d` |
| `--accent` | `#0a84ff` | 同左 |
| `--green` | `#34c759` | 同左 |
| `--amber` | `#ff9f0a` | 同左 |
| `--red` | `#ff453a` | 同左 |
| `--radius` | `16px` | 同左 |

字体：`-apple-system, "SF Pro Text", "PingFang SC", sans-serif`；数字统一 `font-variant-numeric: tabular-nums`。

版式：

- 页面内边距 `32px 20px 48px`，内容最大宽度 `1120px`；
- 卡片内边距 `22px`，≤480px 时 `16px`；
- 卡片间距 `16px`；≥760px 两列等宽，<760px 单列；
- 卡片标题 `12px / 600 / letter-spacing .3px / --dim`。

## 设备卡

标题固定为 `设备 · N`，N 是当前列出的设备数（含本机）。

单行结构（左 → 右）：

| 区域 | 规格 |
|---|---|
| 图标 | 34×34，圆角 9，底色 `rgba(127,127,127,.12)`；Windows 图标色 `#0078d4`，其余用 `--text`/`--dim` |
| 名称 | 15px / 500 |
| 副标题 | 12px / `--dim`，等宽字体；`系统 · tailnet IP`，系统名与设备名相同时只留 IP |
| 时延 | 12px / 等宽数字 / 右对齐；`margin-right: 9px` |
| 路径 | 11px / 行高 15 / 圆角 999 / 横向内边距 7；正文 `Direct` / `Relay` |
| 状态点 | 8px 圆点 + 13px 文案；`margin-right: 6px` |

行内边距 `8px 0`；行悬停不加背景（只读页面不需要 hover 反馈）。

### 时延规范

| 值 | 颜色 | 文本 |
|---|---|---|
| `< 200 ms` | `--green` | `123ms` |
| `200–349 ms` | `--amber` | `240ms` |
| `≥ 350 ms` | `--red` | `420ms` |
| 未知 | `--dim` | `—` |

不要显示 `0ms`、`<1ms` 或估算值；拿不到就显示 `—`。

### 路径徽标

| 值 | 样式 |
|---|---|
| `direct` | 文本 `Direct`，背景 `rgba(52,199,89,.16)`，文字 `--dim` |
| `relay` | 文本 `Relay`，背景 `--amber`，文字 `#fff` |
| 未知 | 不显示徽标 |

### 状态点

| 状态 | 颜色 | 文案 |
|---|---|---|
| 在线 | 绿 | `在线`；本机固定 `本体` |
| 离线 | 红 | `N 分钟前在线` / `N 小时前在线` / `N 天前在线` |
| 未探测 | 灰 | 空 |

颜色不是唯一信号：状态点和文案必须同时存在。

### 图标

全部内联 SVG，`viewBox="0 0 24 24"`，`fill="none"`，`stroke="currentColor"`，`aria-hidden="true"`：

| 类型 | 尺寸 | 线宽 | 形状 |
|---|---|---|---|
| `mac` | 20 | 1.6 | 显示器 + 底座 + 摄像头点 |
| `win` | 20 | 1.6 | 2×2 窗格 |
| `ipad` | 21 | 1.7 | 竖屏平板 + Home 条 |
| `phone` | 20 | 1.7 | 竖屏手机 + Home 条 |
| `other` | 20 | 1.6 | 显示器 + 底座横线 |

不引入图标字体、外部 SVG 或 CDN。

## DSH 主机卡

标题按主执行端显示 `Mac DSH` 或 `Windows DSH`。五行，左标签 13px `--dim`，右值 14px 右对齐：

| 行 | 值 |
|---|---|
| `DSH 界面` | 绿色点 + `运行中` / 红色点 + `未运行` |
| `常驻托管` | 绿色点 + `launchd`（macOS）或 `计划任务`（Windows） / 黄色点 + `手动`、`未接管`、`重启中` |
| `工作区` | 数字 |
| `会话` | `总数 · 最近 N 分钟前` |
| `Tailscale` | 绿色点 + 等宽 tailnet IP / 灰点 + `未连接` |

不显示 DSH 的内部监听端口，不显示启动 token，不显示工作区名字。

截图里的「launchd」需要 macOS 在 `config.json` 填 `dsh.launchdLabel`；Windows 的「计划任务」需要填 `dsh.taskName`。没填时这一行显示「手动」，属于正常状态，不是故障。

## 顶部标签栏

- 「工作台」「DSH」两个按钮，13px，内边距 `6px 14px`，圆角 9；
- 当前标签反色：背景 `--text`，文字 `--bg`；
- 右侧状态：设备/反代都正常时 `● 全部正常`，否则 `● N 项待处理`；
- 工作台视图右侧一个 30×30 圆形刷新按钮；≤480px 时 34×34；
- DSH 视图隐藏状态文字和工作台刷新，改为显示 `xxms`（浏览器到 DSH）+ 刷新按钮；
- 图标按钮只用 SVG 刷新箭头，15px，线宽 2；必须有 `aria-label`。

刷新时图标旋转 0.8 秒；`prefers-reduced-motion: reduce` 下不旋转，按钮功能不变。

## 诊断卡

只有 `issues` 非空时出现，横跨两列：

- 标题 `诊断 · N`；
- 每行一个 8px 状态点 + 一句话，错误用红点，警告用黄点；
- 只写「发生了什么」，不写原因、不写操作说明；本版本不提供修复按钮。

## 文案规则

页面文字只回答「现在是什么状态」和「下一步能做什么」：

| 场景 | 文案 |
|---|---|
| 加载中 | `加载中…` |
| 请求失败 | `刷新失败` |
| 时延未知 | `—` |
| 在线/离线 | `在线` / `N 分钟前在线` |
| 状态汇总 | `全部正常` / `N 项待处理` |
| 页脚 | `更新于 HH:MM:SS` |

不写解释性文字、不写「为什么这样设计」、不写产品说明、不写 `title` 提示。错误态只写原因 + 下一步（如 `刷新失败`），不写背景故事。

## 深色模式

- `<meta name="color-scheme" content="light dark">`；
- `:root { color-scheme: light dark; }`；
- 通过 `@media (prefers-color-scheme: dark)` 切换令牌；
- 不提供手动主题切换。

## 响应式与可访问性

- 两档布局：`<760px` 单列，`≥760px` 两列；
- 在 820×1130（iPad 竖屏）和 1180×820（横屏）下不横向溢出；
- 顶部标签可用键盘聚焦，当前项带 `aria-current="page"`；
- iframe 带 `title="DSH"`；
- 颜色对比度：正文 `--text` 对 `--card` 足够；状态同时用点 + 文案；
- 动效只影响刷新图标，且尊重 `prefers-reduced-motion`。

## 验收

1. 1180×820 与 820×1130 两档截图，布局不溢出、两个卡片顶部对齐；
2. 设备行在长名称/长 IP 下不换行撑破（名称截断或省略，状态区保持右侧）；
3. 时延三档颜色与 `—` 都能复现；
4. Direct / Relay 徽标与状态点同时正确；
5. 深色模式下卡片、文字、状态点可读；
6. 页面不出现存储、入口、文件、流量、设置等本版本范围外的区块。
